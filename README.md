# FPS-OS

A 3D first-person web-based operating system built for Hackclub Stardance

![Banner image of FPS OS, displaying a 3D scene with multiple objects placed around including notepad and browser windows, a clock and a bed.](./src/screenshots/banner.png)

## Usage

Go to [cookistudios.com/fps-os](https://cookistudios.com/fps-os).

- Follow the movement controls of WASD
- Use the mouse to look around
- Click when crosshair has a circle to interact
- When crosshair displays a bar, click and keep held to drag objects
- Right click for context menu
- Use shift to crouch
- Press / for noclip

## Features (WebOS 1)

### Lock screen

Securely lock your OS with the default passcode of 0000.

![Image of lock screen keypad](./src/screenshots/lockscreen.png)

### Markdown text editor

Write messages and throw them out of the windows.

![Splitscreen image of a notepad, left with Markdown and right compiled.](./src/screenshots/notepad.png)

### Virtual machine/web browser

Take a gander at what the internet has to offer. Your history won't save.

![Image of a personal computer inside FPS OS with FPS OS running on it.](./src/screenshots/pc.png)

### Graphics quality presets

Put the FPS back in FPS OS by lowering rendering computation.

![Splitscreen image comparing varying levels of graphics fidelity.](./src/screenshots/graphics.png)

### Sleep mode

Leave the OS open without running. Don't count the Zs for too long or you might drift off aswell.

![Image of a darkened screen with Z letters floating from the center.](./src/screenshots/bed.png)

### Real-time clock

Read the time from an analog clock. Don't know how? Uh...

![Image of a clock hanging on the wall next to a window.](./src/screenshots/clock.png)

### Sound effects

Experience a fully 3D audio experience. The constant sound of the clock ticking reminds you of your mortality.

![Image of a scene presenting different sources of audio.](./src/screenshots/audio.png)

### Physics

Pick up and throw objects at will. The movement system lets you bhop.

![Image of some objects jumbled together in a pile on the floor.](./src/screenshots/physics.png)

### Dark/Light mode

Stick to the default light mode or shut the blinds for a moodier vibe.

![Splitscreen image of a scene comparing shut blinds and ceiling light versus windows open and no ceiling light.](./src/screenshots/lightdark.png)

### Custom wallpaper

Right click a wall to access the context menu. Set your wallpaper to any image. It saves on reload.

![Image of custom wallpaper set to blue face thumbs up emoji.](./src/screenshots/wallpaper.png)
